System Architecture

How CampusBot Works

A five-step Retrieval-Augmented Generation pipeline connecting students with verified college facts.

1

Student Enters a Question

The student types an admission inquiry in the clean chat interface or selects a starter prompt.

2

CampusBot Processes Query

Flask backend receives and sanitizes the query, generating semantic embeddings with local Ollama.

3

RAG Retrieves Context

Cosine similarity search queries the local vector database for the most relevant document passages.

4

Local LLM Generates Answer

Ollama (LLaMA 3.2:3b) receives the retrieved facts alongside system instructions and drafts a grounded answer.

5

Answer & Citations Displayed

CampusBot renders the response in Markdown with exact source filenames and page numbers cited.

About the Project

Engineering College Microproject

CampusBot is an applied Artificial Intelligence engineering project designed to demonstrate the real-world deployment of Large Language Models (LLMs) and Retrieval-Augmented Generation (RAG).

Rather than relying on paid cloud APIs (such as OpenAI or Anthropic), CampusBot is engineered to run 100% locally on standard PC hardware using Ollama's local inference runtime. This demonstrates practical edge computing, strict data privacy, zero recurring cloud expenditure, and verified document grounding.

Core Technologies:

Python 3 Flask 3 Ollama (LLaMA 3.2:3b) Nomic Embed Text SQLite 3 PyMuPDF Vanilla JS & CSS3
Academic viva Demonstration

Fully functional on Windows, demonstrable locally to evaluators and professors.

$0.00 Running Cost

Zero paid tokens, zero recurring cloud bills, 100% open-source local stack.

Document Grounding

Avoids LLM hallucinations by restricting institutional claims to indexed college text.
