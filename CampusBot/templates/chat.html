Setting Up Local Ollama AI

                        100% Free • Windows Local Execution
                    

                

                
            

            

                
CampusBot runs 100% free locally on your computer using Ollama. To start inference:

                
    
                    
  1. 
                        1. Download and Install Ollama for Windows:
                        
    Download from ollama.com/download/windows and install.
    
                    
    2. 
                    
  2. 
                        2. Pull the chat model:
                        
    Open Command Prompt or PowerShell and run:
    
                        
    
                            ollama pull llama3.2:3b
                        
    
                        
    Document retrieval uses a built-in offline search, so no separate embedding model download is required.
    
                    
    3. 
                    
  3. 
                        3. Verify Ollama is running:
                        
    Ensure the Ollama icon is visible in your Windows system tray or run ollama serve.
    
                    
    4.
